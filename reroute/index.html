NOTES & PLAN
  • 数据来源：钉钉表格 reroute to 3PL（Report by SC / Report by HUB / reverse order 三个 Sheet），背景与流程见 重路由计划。
  • 统计口径：按 Sheet 中 Date 列（MMDD）逐日聚合；「已重路由」= done by Tony 列为 DONE；「SC 发起」含分拨内库存 + 管道内捞单（现 Sheet 中由 TONY 统一登记执行）；「HUB 发起」= HUB 内库存订单；「逆向」= 逆向转正向（履约订正工具处理，单独统计）。
  • 重路由计划：三类订单自 10/28 起正式执行，单次重路由限额 500 单；管道内订单每日 10:00 / 17:00 各捞单上报一次；10/30 后所有 RD 订单须在进入分拨（DME / OVB / VVO）前完成重路由。
  • 流向规则：自提单 RD-Locker&PUDO → CDEK-PUDO 或 X5-PUDO（距离优先）；到门单 RD-to-door → CDEK-to-door（YANDEX 因莫斯科可用区A战争风险暂不启用）。
  • 看板更新：每日定时重读源表并重新发布；点位实时单量另见 FBI 点位报表。3PL 提货车辆由 Lyudmila 定时观测分拨 3PL 单量后通知增派。
  • 前缀↔HUB 映射：订单号前缀按运单号规则关联 RESCODE Detail 表 的 RESCODE NAME（B 列），用于识别订单来源 HUB。
